## `_brain/` renamed to `_implant/`; vocabulary made consistent

Tom's instruction: this repository is not a brain, it is an **implant**.
brainpick registers exactly one repository per agent as its **cortex** (the
agent's own brain). Every other registered repository, or a subfolder of one,
is an implant. So every `brain-implant-*` repository keeps its data in
`_implant/`, as the philosophy and cognitive-tools implants already did. This
one, apologetics and stem now follow.

- The bundle root was renamed with `git mv`, and every path in the contract,
  tools, README and `brainpick.toml` now says `_implant`.
- The prose now says *implant* where it meant this repository. brainpick's own
  terms stay as they are (`brain://`, `brain_*`, *brain format 3*, `[brain]`),
  because they name the engine's concepts.
- The usage skill is now [Using the brain implant](../../../../skills/using-the-brain-implant.md),
  and explains cortex versus implant.
- The plan gained a *Status and how to resume* section, so work can restart
  from the repository alone after a break
  ([plan](../../../../plans/mvp-then-iteration.md)). Its description of the binding
  was corrected from the dropped `[[…]]{brain://…}` form to the autolinks
  actually in use.

Archived journals keep their original wording because they are history.
