# Genesis 11

Verses are addressed by atomic reference token — `gen11v1` is Genesis 11:1 — because the search tokenizer splits `Genesis 11:1` into separate terms and cannot then tell it from `Genesis 1:11`. See [addressing scripture](../../conventions/addressing-scripture.md).
