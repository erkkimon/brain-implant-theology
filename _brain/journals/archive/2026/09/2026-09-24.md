# 2026-09-24

## Theology implant scaffolded, and the verse-addressing problem solved first

Scaffolded the bundle — folders, indexes, conventions, vision — after settling
the one question that would have invalidated the whole structure if discovered
later.

**The question**: how does an agent asked about interpretations of John 14:6
find them? Finding content *by verse*, not a verse by content.

**The finding**: brainpick's keyword retrieval is BM25 over the Unicode
tokenizer `[^\W_]+`, so punctuation separates. `John 14:6` indexes as `john`,
`14`, `6` — and `John 6:14` indexes as exactly the same three terms. BM25 has
no word order, so the two references are not similar but *indistinguishable*.
Worse, a chapter document contains verse numbers 1..n, making bare digits the
highest-frequency tokens in the corpus, and `Room. 8:28` collides with the
English word "room".

**The fix**: an atomic reference token, `jhn14v6` — one unbroken alphanumeric
string the tokenizer cannot split. Verified `jhn14v6` and `jhn6v14` index
distinctly. Bonus: the tokenizer emits a 4-character prefix stem for tokens of
5+ characters, so `jhn14v6` also yields `jhn1`, giving chapter-level recall for
free. The token goes in chapter frontmatter, in each verse heading (so
`brain_read`'s `sections` parameter can fetch one verse without the chapter),
and in every article arguing from the verse — which is what makes one search
return the text *and* everyone who interpreted it.

No custom tool needed. The convention is the mechanism; a tool here would have
been a workaround for a formatting decision we can simply make correctly.
Written up in `conventions/addressing-scripture.md`.

Four epistemic conventions copied from the apologetics implant unchanged in
substance — they are tradition-neutral — with the publication rule's seventh
point rewritten from ApoWiki IP pseudonymisation to scripture redistribution
licensing, which is this implant's equivalent hazard.

## The Bible is in: 1,189 chapters, and a licence that says no

Ingested the complete King James Version — 66 books, 1,189 chapters, 31,102
verses — as the reference implementation of the chapter-plus-token shape.
Generated in **0.18 seconds** by `skills/tools/bible_ingest.py`, with no model
calls: the whole thing is deterministic string work, and it is idempotent, so
a re-run diffs empty.

**The licence audit is the part worth remembering.** Surveyed all 30-odd
translations on raamattu.uskonkirjat.net against their own copyright page. The
headline finding is negative and unambiguous: **Raamattu 1992 — the standard
modern Finnish translation, the one a Finnish reader expects — forbids
copying and redistribution outright.** It belongs to Kirkon keskusrahasto and
only personal study retrieval is permitted. Not a grey area to argue around;
the only route is a written licence request.

So the Finnish spine must be **Raamattu 1933/38** and **Biblia 1776**, both in
free use, with 1992 cited by reference only. Also rejected: STLK 2017
(CC BY-NC-ND — ND forbids the derivative that chapter-splitting is), NET
(non-commercial), ISV ("without changes"), Green's Literal, Folkbibeln, and
JPS Tanakh 1917 (PD by age, but this electronic edition is claimed). Cleared:
KJV, ASV, Young's, Darby, Segond, Luther 1545, Vulgata, Septuaginta, Textus
Receptus, Westcott-Hort, Biblia Hebraica. Full reasoning in
`raw/translations/licence-audit.md`.

Two contract lessons landed while doing it. `LICENCE.md` collides with the
kebab-case rule for `raw/`, and the licence convention should win — a licence
file nobody recognises is a licence nobody honours, so it is now exempt.
And the ingest tool was not idempotent on its first two runs: the merge path
and the fresh path disagreed by a single trailing newline, so every re-ingest
rewrote all 1,189 files. Found by diffing consecutive runs rather than by
trusting the "written/unchanged" counter, which was itself reporting from the
wrong side of the merge.

Embedding 1,189 chapters is ~32,000 chunks at roughly 174 ms each on
bge-m3 — about 94 minutes, measured rather than guessed. Worth knowing before
assuming a compile has hung.
