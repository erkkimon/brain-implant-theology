# Raw

Undistilled source material: downloaded translations, scanned confessions,
transcripts. No frontmatter, no links required, but orderly — kebab-case names
that say what a file is, listed here, pruned once distilled. brainpick excludes
this folder from search results; grep it.

## Folders

* `translations/` — scripture texts as fetched from their sources, one folder
  per translation, each carrying a `LICENCE.md` stating its redistribution
  terms. A translation whose licence forbids redistribution is **not** stored
  here; it is cited by reference only.
